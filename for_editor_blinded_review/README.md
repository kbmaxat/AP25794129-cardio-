# Editor Review Folder

This folder contains an anonymized code package intended for blinded peer review download.

Package location:

- `for_editor_blinded_review/cardiac-preprocessing-benchmark/`

Notes:

- No real patient data are included.
- The package is research software (not a clinical diagnostic system).
- The package content is prepared for editor/reviewer distribution.
- Reported benchmark tables, where included, are transcribed from the submitted manuscript version; no post-hoc retraining or parameter tuning was performed to fit those values.
- This package was originally prepared for a blinded review process. It is kept here for provenance and can be reused or updated if a future submission requires an anonymized review package.
